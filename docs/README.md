# Documentation Directory

This directory contains all documentation for the PeakActivity project.

## Structure
- **api/**: API documentation (Swagger/OpenAPI)
- **user/**: User manuals and guides
- **developer/**: Developer guides and architecture
- **adr/**: Architectural Decision Records
- **diagrams/**: Architecture and data flow diagrams

## Guidelines
- All docs in English and Turkish
- Use Markdown format
- Include code examples where appropriate
- Keep documentation up-to-date with code changes
- Use consistent formatting and structure
