# Product direction

This high-level roadmap describes targets, not release commitments or dates.

Experimental: the inherited Tauri desktop shell, optional SQLCipher support and
pre-storage event filtering provide the starting point.
<!-- capability:desktop:Experimental -->
<!-- capability:sqlcipher:Experimental -->
<!-- capability:storage-filter:Experimental -->

Planned: encrypted-by-default storage, native key lifecycle, scoped local API access,
visible recording controls, retention, and an outbound Privacy Firewall.
<!-- capability:encrypted-default:Planned -->
<!-- capability:privacy-firewall:Planned -->

Experimental: deterministic rules, basic reports, and manual time entry are limited
foundations; custom category weights are user-selected and do not compare people.
<!-- capability:deterministic-rules:Experimental -->
<!-- capability:insights-reports:Experimental -->
<!-- capability:manual-time-entry:Experimental -->

Planned: E2EE synchronization, encrypted backup and recovery. Synchronization
requires a published protocol and independent review.
<!-- capability:e2ee-sync:Planned -->

Planned: paid services, premium local workflows, and the separate Freelancer
workspace for user-approved project, timesheet, and integration tools. Core privacy
controls remain usable without payment.
<!-- capability:commercial:Planned -->
<!-- capability:freelancer-workspace:Planned -->

Planned: an Android client and a limited iOS companion. Mobile support will reflect
OS restrictions instead of promising desktop-equivalent capture.
<!-- capability:android:Planned -->
<!-- capability:ios:Planned -->

Planned: Peak AI, Custom Endpoint and a permissioned plugin ecosystem. AI remains
optional, with explicit request approval and no automatic provider fallback.
<!-- capability:peak-ai:Planned -->
<!-- capability:custom-endpoint:Planned -->
<!-- capability:plugin-ecosystem:Planned -->

Planned: a branded browser extension after its data permissions and provenance
have been reviewed.
<!-- capability:browser:Planned -->

Planned: the branded product website and verified desktop update-integrity flow.
<!-- capability:website:Planned -->
<!-- capability:desktop-update-integrity:Planned -->

Planned: local notification history for actionable desktop alerts.
<!-- capability:notification-history:Planned -->

Planned: a separate Enterprise product, last, with employee-controlled sharing.
Individual raw activity is not a manager dashboard input.
<!-- capability:enterprise:Planned -->

Unsupported: bundled LLM and on-device LLM execution.
<!-- capability:local-llm:Unsupported -->
