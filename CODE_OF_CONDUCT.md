# Code of conduct

Participate respectfully. Constructive disagreement is welcome; harassment,
threats, discriminatory abuse and publishing another person's private information
are not. These rules apply to project discussions, issues, pull requests and
project representation.

Maintainers may edit or remove abusive content and restrict participation to
protect contributors. Describe problems factually and respect people's boundaries.

A verified confidential conduct-reporting route has not yet been established.
Do not place sensitive reports in a public issue or send them to upstream
maintainers on behalf of this project. Platform reporting controls remain
available for abuse on the hosting platform. This source bootstrap does not claim
an operational confidential reporting service.
